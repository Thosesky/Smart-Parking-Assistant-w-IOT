1. บทคัดย่อ (Abstract)

โครงงานนี้จัดทำขึ้นเพื่อพัฒนา "ระบบผู้ช่วยถอยจอดและเฝ้าระวังอุณหภูมิโรงรถ (Smart Garage Parking Assistant)" โดยมีวัตถุประสงค์เพื่อแก้ปัญหาความยากลำบากในการกะระยะถอยรถเข้าพื้นที่จำกัด ซึ่งอาจก่อให้เกิดอุบัติเหตุเฉี่ยวชน รวมถึงช่วยเฝ้าระวังความร้อนสะสมภายในโรงรถที่อาจส่งผลกระทบต่อตัวรถ ระบบนี้พัฒนาขึ้นโดยใช้บอร์ดไมโครคอนโทรลเลอร์ร่วมกับเซนเซอร์และอุปกรณ์อิเล็กทรอนิกส์ ได้แก่ Ultra Sonic Sensor สำหรับวัดระยะห่างระหว่างท้ายรถกับผนังกำแพงแบบเรียลไทม์, Temp Sensor สำหรับตรวจสอบอุณหภูมิภายในโรงรถ, Keypad สำหรับให้ผู้ใช้ตั้งค่าระยะห่างปลอดภัย และแสดงผลข้อมูลระยะทางหรือสถานะการเตือนผ่านหน้าจอ 7-Segment ผลการดำเนินงานพบว่าระบบสามารถช่วยอำนวยความสะดวกในการถอยจอดได้อย่างแม่นยำ พร้อมทั้งแจ้งเตือนความผิดปกติของอุณหภูมิได้อย่างมีประสิทธิภาพ ช่วยเพิ่มความปลอดภัยให้กับทรัพย์สินและผู้ใช้งานได้เป็นอย่างดี

4. รายละเอียดและ Source Code

ในโครงงาน Smart Garage Parking Assistant (ระบบผู้ช่วยถอยจอดและเฝ้าระวังอุณหภูมิโรงรถ) มีการเชื่อมต่ออุปกรณ์ไมโครคอนโทรลเลอร์เข้ากับเซนเซอร์และโมดูลต่างๆ โดยมีรายละเอียดการทำงานของวงจรและอุปกรณ์แต่ละส่วนดังนี้:

4.1 ภาพรวมการทำงานของวงจร (Circuit Overview)

วงจรหลักถูกออกแบบมาเพื่อติดตั้งบริเวณผนังด้านในสุดของโรงรถ โดยไมโครคอนโทรลเลอร์ทำหน้าที่เป็นศูนย์กลางในการรับสัญญาณข้อมูลจากอุปกรณ์ Input ประมวลผลตรรกะการทำงาน (Logic) และส่งคำสั่งแสดงผลออกไปยังอุปกรณ์ Output อย่างแม่นยำ

4.2 รายละเอียดการทำงานของเซนเซอร์และอุปกรณ์ (Sensors & Modules)

  • Ultra Sonic Sensor (Input): ทำหน้าที่ยิงคลื่นเสียงความถี่สูงเพื่อวัดระยะห่างระหว่างท้ายรถกับผนังกำแพงแบบเรียลไทม์ เพื่อให้ผู้ขับขี่ทราบระยะทางที่เหลือขณะถอยรถเข้าจอด
  • Temperature Sensor (Input): ทำหน้าที่ตรวจสอบอุณหภูมิโดยรอบภายในโรงรถอย่างต่อเนื่อง เพื่อเฝ้าระวังความร้อนสะสมที่อาจเป็นอันตรายต่อตัวรถหรือเสี่ยงต่อการเกิดอุบัติเหตุ
  • 4x4 Membrane Keypad (Input): ใช้สำหรับให้ผู้ใช้งานกดปุ่มตั้งค่าระยะห่างอันตรายที่ต้องการให้ระบบเริ่มส่งสัญญาณเตือน (เช่น ตั้งค่าระยะเตือนไว้ที่ 30 เซนติเมตร)
  • 7-Segment Display (Output): ทำหน้าที่แสดงผลตัวเลขระยะห่างระหว่างรถกับผนัง (หน่วยเป็นเซนติเมตร) และจะเปลี่ยนรูปแบบการแสดงผลเป็นการกะพริบแจ้งเตือน เมื่อรถถอยเข้ามาใกล้เกินระยะที่กำหนดหรือเมื่ออุณหภูมิสูงเกินเกณฑ์
